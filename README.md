# ChatGPT

Ask GPT Pro, ChatGPT's Pro mode, for a focused independent second opinion.

## Skills

| Skill | Does |
| --- | --- |
| `gpt-pro` | Sends a grounded question to a visibly verified ChatGPT Pro mode through the ChatGPT desktop app's in-app browser and fails closed instead of silently using another model or browser. |

## Install

```bash
claude plugin install chatgpt@package-manager
```

```bash
codex plugin add chatgpt@package-manager
```
